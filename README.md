## Windows 使用方法

### 标准安装：中文安装向导

1. 解压 `ProfessionalMonitorTool-1.6.1-windows-x64.zip`。

2. 运行其中的 `ProfessionalMonitorTool-1.6.1-windows-x64-deployer.exe`（标准 Inno Setup 安装程序，简体中文界面）。

3. 向导里选择安装位置（默认 `%LOCALAPPDATA%\Programs\专业监控工具`），最后可勾选是否创建桌面快捷方式（默认勾选）。

4. 装到已有安装的位置时会直接覆盖升级，数据保留。

### 绿色便携：单独的便携 ZIP

解压 `ProfessionalMonitorTool-1.6.1-windows-x64-portable.zip` 到任意文件夹，运行其中的 `ProfessionalMonitorTool.exe` 即可：不写注册表，程序和数据都在该文件夹里（数据在文件夹内的 `data` 子目录），整个文件夹拷走即用，删除即卸载。

### 卸载软件：设置里卸载，后台删除

没有单独的维护程序。卸载在主程序里：**设置 → 数据与迁移 → 卸载软件**。点「确认卸载」后程序关闭，后台脚本删除程序文件、系统注册项与桌面快捷方式，最后弹出一次完成确认。监控数据默认保留（标准安装保留在系统本地目录；绿色便携移到安装目录旁边的备份目录），确认框里可勾选一并删除。从「设置 → 应用」或 Geek Uninstaller 里卸载时，走标准安装程序的卸载器（删除程序文件、注册项与快捷方式，数据保留）；要连数据一起删或用便携版的备份方式，走上面设置里的卸载。主程序仍保留 `--uninstall` 入口（静默卸载 `--uninstall --silent` 全程无界面）。更新仍在主程序「设置 → 版本更新与保存」里，与卸载无关。

绿色便携版的数据默认保存在软件目录的 `data` 文件夹中，移动或备份时更直观。

> 绿色便携模式的含义是“不注册为已安装应用”，不是隐藏文件。知道实际目录的人仍然可以看到程序文件。

## macOS 使用方法

Release 提供两个单独 ZIP：

- Apple Silicon（M1/M2/M3/M4 等）：`ProfessionalMonitorTool-1.6.1-macos-arm64.zip`

- Intel Mac：`ProfessionalMonitorTool-1.6.1-macos-x64.zip`

解压对应 ZIP，安装其中的 PKG。

## Chrome 浏览器连接器

三个平台 ZIP 都自带 `浏览器插件` 文件夹（ZIP 内只有安装文件和浏览器插件）。

1. 打开 Chrome：`chrome://extensions`

2. 开启「开发者模式」。

3. 点击「加载已解压的扩展程序」。

4. 选择 ZIP 解压后的 `浏览器插件` 文件夹。

5. 打开专业监控工具和需要用于巡检的 Chrome Profile，连接器会在同一台电脑上自动发现软件，无需配对码；首次连接新浏览器时软件内需点一次确认。

6. 一个连接器在线时自动使用；多个连接器在线时可在软件左侧边栏「浏览器连接状态」中单选或多选，并行分配任务。

也可以在软件内打开「浏览器连接」窗口，点「导出连接器」重新获取最新版连接器（当前版本 1.4.1）。

## 巡检与数据

- 软件启动默认不自动巡检，除非用户在设置中明确开启。
- 默认每轮基准间隔 120 分钟，并随机提前或延后 15–25 分钟。
- 两个主页之间默认随机等待 6–9 秒。
- 页面名称、头像、粉丝数据和最近发帖时间由浏览器连接器读取。
- 设置与数据会跨重启保留。
- 绿色便携模式默认把数据保存在程序目录下；标准模式继续使用正常用户数据目录。
- 主题共 3 个：云白（默认）、护眼绿、曜石黑；可在左侧边栏底部或设置里切换。
- 监控模块：粉丝增长监控默认开启，发帖时间监控默认关闭；首次运行会问一次，之后可在设置「监控模块」里改。关闭发帖监控只屏蔽显示、采集与提醒，不删除已保存的发帖标准与历史提醒，重新开启即恢复。

## 更新

软件只提示正式稳定版本。更新检查在启动后与每 6 小时静默进行，不打扰；手动检查会在界面给可见反馈。

发现新版后，安装版（Windows 安装程序 / macOS PKG 安装的版本）的流程是：

1. 后台下载当前系统对应的更新包。
2. 按发布清单做 SHA-256 校验，并校验下载地址属于官方仓库发布页；校验失败绝不安装。
3. 空闲时（没有正在进行的巡检）自动退出、安装并重启；安装过程不弹确认框。正在巡检时会等到有空或由用户在更新弹窗里手动处理。
4. 可在「设置 → 更新」里关闭「下载完成后自动安装更新」；关闭后恢复为弹窗确认的方式。

关于签名：v1.6.0 起，自动安装不再要求付费代码签名指纹。校验链是 HTTPS + 官方仓库地址 + SHA-256，足以确认“下载到的文件就是本次发布的文件”。但要说清楚它的边界：如果攻击者拿到了仓库账号并发布了恶意版本与配套清单，哈希校验也会通过；付费证书的指纹校验能挡住这一手（攻击者没有证书私钥）。不花钱的折中办法是自签证书（一条 PowerShell 命令生成，免费），把指纹填进源码后重新走云端构建，即可恢复发布者校验；自签包首次运行仍可能触发 SmartScreen 提示，这是系统行为，与自动升级无关。

源码（`.py` / `.pyw`）运行方式不自动覆盖脚本：下载完成后请手动运行其中的部署文件。

每个 ZIP 内包含当前系统的安装文件（安装程序 / 便携版文件 / PKG）与 `浏览器插件/`。

不包含 Python 源码，不包含 `README.md` 与软件图标，不额外上传单独插件 ZIP。
