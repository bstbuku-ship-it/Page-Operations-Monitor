# 专业监控工具

用于监控 Facebook 公共主页的粉丝增长、最近发帖时间、主页活跃情况与异常预警的桌面工具。

## Windows 使用方法

### 标准安装

1. 解压 `ProfessionalMonitorTool-<版本号>-windows-x64.zip`。
2. 运行其中的 `ProfessionalMonitorTool-<版本号>-windows-x64-deployer.exe`（标准 Inno Setup 安装程序，简体中文界面）。
3. 在向导中选择安装位置（默认 `%LOCALAPPDATA%\Programs\专业监控工具`），可选择是否创建桌面快捷方式（默认勾选）。
4. 安装到已有安装的位置时会直接覆盖升级，数据保留。

### 绿色便携版

解压 `ProfessionalMonitorTool-<版本号>-windows-x64-portable.zip` 到任意文件夹，运行其中的 `ProfessionalMonitorTool.exe` 即可。

- 不写注册表，程序与数据都在该文件夹内（数据位于 `data` 子目录）。
- 整个文件夹拷走即可使用，删除文件夹即卸载。

> 绿色便携模式的含义是「不注册为已安装应用」，不是隐藏文件。知道实际目录的人仍然可以看到程序文件。

### 卸载

- **标准安装版**：在 Windows「设置 → 应用」或 Geek Uninstaller 中卸载，将运行安装程序自带的卸载器，删除程序文件、注册项与桌面快捷方式，监控数据默认保留。
- **命令行**：运行 `ProfessionalMonitorTool.exe --uninstall` 可调出卸载确认框，可在确认框中勾选同时删除监控数据；`--uninstall --silent` 为全程无界面的静默卸载。
- **绿色便携版**：直接删除软件文件夹即可。

## macOS 使用方法

Release 提供两个独立的 ZIP：

- Apple Silicon（M1 / M2 / M3 / M4 等）：`ProfessionalMonitorTool-<版本号>-macos-arm64.zip`
- Intel Mac：`ProfessionalMonitorTool-<版本号>-macos-x64.zip`

解压对应 ZIP，安装其中的 PKG 即可。

## Chrome 浏览器连接器

三个平台的 ZIP 均自带 `浏览器插件` 文件夹。

1. 打开 Chrome，进入 `chrome://extensions`。
2. 开启「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择解压后的 `浏览器插件` 文件夹。
5. 打开专业监控工具以及需要用于巡检的 Chrome 配置，连接器会在同一台电脑上自动发现软件，无需配对码；首次连接新浏览器时，需在软件内确认一次。
6. 一个连接器在线时自动使用；多个连接器在线时，可在软件左侧边栏「浏览器连接」中单选或多选，并行分配任务。

如需重新获取最新版连接器（当前版本 v1.4.7），可在软件内打开「浏览器连接」窗口，或进入「设置 → 连接与更新」，点击「获取连接器」。

## 巡检与数据

- 软件启动后不会自动开始巡检，需在首页点击「启用自动巡检」。
- 默认每轮基准间隔 240 分钟，并随机提前或延后 15–25 分钟。
- 相邻两个主页之间默认随机等待 6–9 秒。
- 页面名称、头像、粉丝数据与最近发帖时间由浏览器连接器读取。
- 设置修改后自动保存，重启后继续生效。
- 绿色便携版的数据默认保存在程序目录下的 `data` 文件夹；标准安装版使用系统用户数据目录。可在「设置 → 数据管理」中更改保存目录，现有数据会一并迁移。
- 主题共 3 个：云白（默认）、护眼绿、曜石黑，可在「设置 → 外观」中切换。
- 监控模块：粉丝增长监控默认开启，发帖时间监控默认关闭。首次运行会询问一次，之后可在「设置 → 监控模块」中更改。关闭发帖监控只会隐藏显示、停止采集与提醒，不会删除已保存的发帖标准和历史提醒，重新开启即可恢复。

## 软件更新

软件只提示正式稳定版本。更新检查在启动后及每 6 小时静默进行，不打扰使用；手动检查会在界面中给出明确反馈。可在「设置 → 连接与更新」中管理启动时的更新检查。

安装版（Windows 安装程序 / macOS PKG）发现新版后的流程：

1. 后台下载当前系统对应的更新包。
2. 按发布清单进行 SHA-256 校验，并确认下载地址属于官方仓库发布页；校验失败不会安装。
3. 空闲时（没有正在进行的巡检）自动退出、安装并重启，安装过程不弹确认框；正在巡检时会等待空闲。

关于校验方式：自动安装的校验链为 HTTPS、官方仓库地址与 SHA-256，可以确认下载到的文件就是本次发布的文件；但如果仓库账号被盗用并发布了恶意版本与配套清单，哈希校验同样会通过，请妥善保管仓库账号。

源码（`.py` / `.pyw`）运行方式不会自动覆盖脚本，下载完成后请手动运行其中的部署文件。
